# HighRound

**EN** · [FR](#français)

Guides, Easter Eggs, tips and strategies for every Call of Duty Zombies mode — from World at War to the latest releases — gathered in one clear place, in English and French.

Website and apps share the same content and the same layout.

## Platforms

| Platform | Format |
|---|---|
| Web | Any screen: phone, tablet, laptop, desktop, ultrawide — hosted on GitHub Pages |
| Windows | `.exe` installer (Releases) |

On phones and tablets, use the website — no store app needed.

Built with [Astro](https://astro.build) (site) and [Tauri](https://tauri.app) (Windows app) — one codebase, light and fast.

## Covered games

World at War · Black Ops · Black Ops II · Black Ops III · Black Ops 4 · Black Ops Cold War · Black Ops 6 · Black Ops 7 · Advanced Warfare (Exo Zombies) · Infinite Warfare · WWII (Nazi Zombies) · Vanguard · Modern Warfare III
