Les **tremplins** (jump pads) de la base t'envoient d'une zone de défense à l'autre pour **500 Essence** le saut. Avec ce petit jeu de « Jacques a dit », ils deviennent **gratuits** pour le reste de la partie.

## Les six tremplins

| Tremplin | Il t'envoie à |
| --- | --- |
| **Jungle Defense** (1) | Scorched Defense |
| **Jungle Defense** (2) | Rocky Defense |
| **Mission Control**, à l'intérieur | Jungle Defense |
| **Mission Control**, juste à côté | Rocky Defense |
| **Data Center** | Scorched Defense |
| **Rocky Defense**, à l'étage | Jungle Defense |

{/* Destinations: Charlie Intel only. Which of the two Jungle / Mission Control pads is "1" or "2" in mmmrkennedy's list is not stated. */}

## Les rendre gratuits

<Checklist>
  <Step title="Rétablis le courant">
    Les tremplins marchent avec le courant, et le Pack-a-Punch doit être actif. Voir [Rétablir le courant (les 3 réacteurs)](../courant/).
  </Step>

  <Step title="Utilise chaque tremplin une fois">
    Saute au moins une fois avec **chacun des six** tremplins. Ça coûte 3 000 Essence en tout.

    <Shots>
      <Screenshot src={m + 'jungledefense1.webp'} alt="Premier tremplin de la Jungle Defense" credit={by} source={src} />
      <Screenshot src={m + 'jungledefense2.webp'} alt="Deuxième tremplin de la Jungle Defense" credit={by} source={src} />
      <Screenshot src={m + 'missioncontrol1.webp'} alt="Premier tremplin de Mission Control" credit={by} source={src} />
      <Screenshot src={m + 'missioncontrol2.webp'} alt="Deuxième tremplin de Mission Control" credit={by} source={src} />
      <Screenshot src={m + 'datacenter.webp'} alt="Le tremplin du Data Center" credit={by} source={src} />
      <Screenshot src={m + 'rockydefence.webp'} alt="Le tremplin de la Rocky Defense" credit={by} source={src} />
    </Shots>
  </Step>

  <Step title="Trouve la lumière verte">
    Un des tremplins a une **lumière verte** sur son panneau de gauche. Tire dessus : des **flèches** s'affichent sur son écran.

    <Screenshot src={m + 'greenlight.webp'} alt="La lumière verte sur le panneau d'un tremplin" credit={by} source={src} />
  </Step>

  <Step title="Bouge dans le sens des flèches">
    Déplace ton personnage dans le sens de chaque flèche, vite et sans te tromper : **cinq mouvements** par tremplin. Si c'est bon, tu es envoyé vers le tremplin suivant, qui a la lumière verte à son tour. Recommence.

    Les séquences sont **toujours les mêmes** :

    | Tremplin | Séquence |
    | --- | --- |
    | Jungle Defense | Gauche, droite, gauche, droite, gauche |
    | Jungle Defense | Haut, droite, gauche, haut, gauche |
    | Mission Control | Haut, bas, haut, bas, haut |
    | Mission Control | Droite, bas, haut, gauche, droite |
    | Data Center | Bas, gauche, droite, gauche, haut |
    | Rocky Defense | Haut, droite, gauche, droite, bas |

    {/* TO CHECK: sequences from mmmrkennedy and tracker.gg, which share the same text (one source). MysteryHQ's description (z-kXPM7KDzc) links an image of them, not readable as text. */}
  </Step>

  <Step title="Finis les six">
    Après le sixième, tous les tremplins sont **gratuits** jusqu'à la fin de la partie.
  </Step>
</Checklist>
