Le réalisateur **Kevin Smith** se joue sur Rave in the Redwoods grâce à un code à taper dans le salon d'avant-partie, avec les flèches de la croix directionnelle ou du clavier. Le débloquer donne le succès « Super Slacker ».

<Checklist>
  <Step title="Termine l'Easter Egg principal une fois">
    Une seule fois suffit, dans n'importe quelle partie. Voir [Easter Egg principal (Locksmith)](../easter-egg-principal/).
  </Step>

  <Step title="Tape le code de Kevin Smith">
    Sélectionne Rave in the Redwoods, puis tape : **droite, gauche, gauche, bas, bas, droite**. L'icône de Kevin Smith apparaît : tu le joues au lancement de la partie.

    <Screenshot src={m + 'smith_code/kevin_smith_icon.webp'} alt="L'icône de Kevin Smith dans le salon" credit={by} source={src} />

    <Tips>
      <Tip type="mistake" author="mmmrkennedy" source={src}>
        Si tu ouvres un autre menu (Caserne, équipement…) après le code, l'icône disparaît : il faut retaper le code.
      </Tip>
    </Tips>
  </Step>
</Checklist>
