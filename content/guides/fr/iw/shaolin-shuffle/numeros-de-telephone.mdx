Les téléphones publics des deux stations de métro se composent comme de vrais téléphones. Certains numéros donnent une réponse spéciale. Plusieurs s'écrivent avec les lettres du clavier (entre parenthèses).

| Numéro | Ce que tu entends |
| --- | --- |
| 0 | Une opératrice |
| 49 (IW) | La tonalité « occupé » |
| 69 | La victime d'un canular téléphonique |
| 232 (CDC) | Un message automatique des Centres pour le contrôle des maladies |
| 411 | Un message automatique de Big Apple Info |
| 666 | Des messages automatiques de Beast Incorporated |
| 911 | Les services d'urgence |
| 2333 (BEEF) | Un employé de Burger Town |
| 3323 (DEAD) | Une femme désemparée |
| 7399 (SEXY) | Une chanson |
| 34726 (DISCO) | Une publicité pour la boîte de nuit Disco |
| 736348 (SENDIT) | Le bruit d'un fax |
| 9328437 (WEATHER) | La météo |
| 369686337 (DOWNUNDER) | Un son de didgeridoo |
| 5550152 | Un homme en colère, seulement pendant l'étape du crâne 6 de Skullbuster |

Le **555-0152** sert à la quête Skullbuster : voir [Skullbuster (tous les atouts pour toute la partie)](../skullbuster/).
