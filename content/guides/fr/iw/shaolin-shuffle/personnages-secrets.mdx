Pam Grier, la prof de kung-fu du Dojo, se joue sur Shaolin Shuffle grâce à un code à taper dans le salon d'avant-partie, avec les flèches de la croix directionnelle ou du clavier.

<Checklist>
  <Step title="Termine l'Easter Egg principal une fois">
    Une seule fois suffit, dans n'importe quelle partie. Voir [Easter Egg principal (Pest Control)](../easter-egg-principal/).
  </Step>

  <Step title="Tape le code de Pam Grier">
    Dans le salon, sélectionne Shaolin Shuffle, puis tape : **haut, haut, droite, gauche, bas, gauche**. L'icône de Pam Grier apparaît : tu la joues au lancement de la partie.

    <Screenshot src={m + 'grier_code/pam_grier_icon.webp'} alt="L'icône de Pam Grier dans le salon" credit={by} source={src} />
  </Step>
</Checklist>

<Tips>
  <Tip type="mistake" author="mmmrkennedy" source={src}>
    Si tu ouvres un autre menu (Caserne, équipement…) après le code, l'icône disparaît : il faut retaper le code. Il faut aussi le retaper avant chaque partie.
  </Tip>
</Tips>

Battre le Rat King en jouant Pam Grier débloque le succès « Exterminator ». La quête des nunchakus, elle, ne se fait pas avec Pam.
