Les zombies lâchent parfois des **pièces souvenir** rouges, bleues ou vertes. Mets-en trois dans une borne à souvenirs, dans n'importe quel ordre, pour fabriquer un objet.

- **Cosmic Way** : près de la porte de Journey into Space.
- **Journey into Space** : en face de l'accès au sous-sol.
- **Astrocade** : dans l'allée derrière l'Astrocade.
- **Polar Peak** : dans la boutique.
- **Kepler** : près de l'escalier du Moonlight Cafe.

## Les recettes

| Objet | Pièces |
| --- | --- |
| Medusa Device | rouge, rouge, rouge |
| Piège feu d'artifice | rouge, rouge, bleue |
| Piège laser de fenêtre | rouge, bleue, bleue |
| Tourelle | bleue, bleue, bleue **ou** rouge, verte, verte |
| Radiocassette | rouge, rouge, verte **ou** verte, verte, bleue |
| Piège électrique | verte, bleue, bleue |
| Revocator | verte, verte, verte |
| Kindle Pops | rouge, verte, bleue |

Certaines bornes donnent aussi une pièce d'arme du rock avec une recette précise : voir les guides du Head-Cutter, du Face-Melter, du Dischord et du Shredder.
