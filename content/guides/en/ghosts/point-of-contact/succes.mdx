Point of Contact has **9 achievements** (trophies on PlayStation), all **hidden**, worth **185 G** on Xbox. They are all bronze, except **Throttled Escape**, which is a **gold** trophy on PlayStation. The names are the in-game English ones.

Play on **Regular** or **Hardcore** difficulty: progression achievements don't count on Casual. Tick them off as you go: your progress stays on your device.

<Checklist>
  <Step title="City Dweller, bronze">
    20 G. Enter the city, the second zone, after the first barrier hive. See [Map walkthrough](../deroulement/).
  </Step>

  <Step title="Cabin Fever, bronze">
    10 G. Enter the cabins zone, the third one, after the second barrier hive.
  </Step>

  <Step title="Made it Out Alive, bronze">
    20 G. Escape for the first time: arm the bomb and reach the helicopter before the timer runs out. See [The final escape](../evasion/).
  </Step>

  <Step title="Sprinter, bronze">
    20 G. Reach the helicopter with at least **1 min 30** left on the 4-minute timer: you have 2 min 30 for the run. Prepare everything before arming the bomb (turrets, armor, Feral Instincts) and run with your pistol out.
  </Step>

  <Step title="No Man Left, bronze">
    20 G. Escape with **all four players** alive in the extraction circle. So you need to play with four. Try it at the same time as Sprinter.
  </Step>

  <Step title="Throttled Escape, gold">
    10 G. Escape with **at least one relic** active. You need to have gone through at least one prestige (level 30) to unlock the first relic. See [Extinction basics](../bases-extinction/).

    PSTHC recommends the **Pistols Only** relic and leveling up health first.
  </Step>

  <Step title="Any Means necessary, bronze">
    40 G. Kill **50 aliens** with the **electric fences** and the **fire traps** in a single match. A fence costs $500, a fire trap $750 according to one source. Spot the traps near each hive and activate them right after placing the drill. On a full match, you easily go past 100 kills.

    {/* TO CHECK: fire trap 750 = PSTHC only. */}
  </Step>

  <Step title="Trash Picker, bronze">
    20 G. **Search 40 objects** (bags, crates, boxes) in a single match. There would be around fifty on the map.

    An object can only be searched by **one player**: in co-op, let one player search everything. In a new zone, the aliens only attack once the drill is placed: search everything before.

    {/* TO CHECK: about 50 search spots = PSTHC only. */}
  </Step>

  <Step title="Completionist, bronze">
    25 G. Complete **the challenge of every drilled hive** in a single match, then escape. There are 12 hives to drill, so 12 challenges to complete.

    {/* TO CHECK: PSTHC says "14 défis" (maybe counting the 2 barrier hives, which have no drill); Eric Barnes' Completionist run (GCnvsxaoPGY chapters) shows 12 challenges, one per drilled hive. */}

    The challenges are drawn at random from those in the table. In solo, the numbers are smaller.

    | Challenge | Solo | 4 players |
    | --- | --- | --- |
    | Take no damage from aliens | | |
    | Get only melee kills (or kill 5 Scouts in melee) | | |
    | Keep 75% accuracy, or 50% | | |
    | Don't reload for 60 seconds | | |
    | Kill aliens while prone | 15 | 25 |
    | Kill aliens with your pistol | 15 | 25 |
    | Kill aliens with the propane tanks | 5 | 10 |
    | Kill aliens with the traps | 5 | 10 |
    | Kill aliens while they are in the air | 3 | 5 |
    | Find and kill the Leper in 30 seconds | | |
    | Spend nothing for 2 minutes | | |
    | Spend an amount before the hive ends | $6,000 | $10,000 or $20,000 |
    | Use no ability for 90 seconds | | |
    | Take no damage from Seekers | | |
    | Kill a Scorpion in melee | | |
    | Keep the drill above 50% | | |

    Co-op only: kill 25 aliens with a set weapon type (shotgun, sniper rifle, assault rifle, machine gun), kill 15 aliens with the turrets, prevent a player from going down, don't bleed out.

    {/* Solo list: Prelude785At chapters (17 solo challenges). 4-player numbers and co-op-only ones: PSTHC. IGN gives the same kinds of challenges. */}

    <Tips>
      <Tip type="tech" author="PSTHC" source="https://www.psthc.fr/unjeu/call-duty-ghosts-ps3/guide-trophees.htm">
        For 75% accuracy: hit a target only once, then let the turrets, melee and traps do the rest. For the Leper, activate Feral Instincts: it is the only alien that doesn't come toward you.
      </Tip>
    </Tips>
  </Step>
</Checklist>
