The payphones in both subway stations dial like real phones. Some numbers give a special answer. Several are spelled with the letters on the keypad (in brackets).

<Screenshot src={m + 'skullbuster/skull_6/payphone.webp'} alt="A subway payphone" credit={by} source={src} />

| Number | What you hear |
| --- | --- |
| 0 | An operator |
| 49 (IW) | The busy tone |
| 69 | The victim of a prank call |
| 232 (CDC) | An automated message from the Centers for Disease Control |
| 411 | An automated message from Big Apple Info |
| 666 | Automated messages from Beast Incorporated |
| 911 | Emergency services |
| 2333 (BEEF) | A Burger Town employee |
| 3323 (DEAD) | A distressed woman |
| 7399 (SEXY) | A song |
| 34726 (DISCO) | An ad for the Disco nightclub |
| 736348 (SENDIT) | A fax machine sound |
| 9328437 (WEATHER) | The weather forecast |
| 369686337 (DOWNUNDER) | A didgeridoo sound |
| 5550152 | An angry man, only during the skull 6 step of Skullbuster |

**555-0152** is used for the Skullbuster quest: see [Skullbuster (every perk for the whole game)](../skullbuster/).
