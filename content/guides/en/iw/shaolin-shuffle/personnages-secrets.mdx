Pam Grier, the Dojo's kung fu teacher, is playable on Shaolin Shuffle with a code you enter in the pre-game lobby, using the arrows of the D-pad or the keyboard.

<Checklist>
  <Step title="Finish the main Easter Egg once">
    Once is enough, in any game. See [Main Easter Egg (Pest Control)](../easter-egg-principal/).
  </Step>

  <Step title="Enter Pam Grier's code">
    In the lobby, select Shaolin Shuffle, then enter: **up, up, right, left, down, left**. Pam Grier's icon appears: you play as her when the game starts.

    <Screenshot src={m + 'grier_code/pam_grier_icon.webp'} alt="Pam Grier's icon in the lobby" credit={by} source={src} />
  </Step>
</Checklist>

<Tips>
  <Tip type="mistake" author="mmmrkennedy" source={src}>
    If you open another menu (Barracks, loadout…) after the code, the icon disappears: enter the code again. You also have to enter it again before each game.
  </Tip>
</Tips>

Beating the Rat King as Pam Grier unlocks the "Exterminator" achievement. The nunchucks quest, however, can't be done as Pam.
