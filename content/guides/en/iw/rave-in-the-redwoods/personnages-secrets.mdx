Director **Kevin Smith** is playable on Rave in the Redwoods with a code you enter in the pre-game lobby, using the arrows of the D-pad or the keyboard. Unlocking him gives the "Super Slacker" achievement.

<Checklist>
  <Step title="Finish the main Easter Egg once">
    Once is enough, in any game. See [Main Easter Egg (Locksmith)](../easter-egg-principal/).
  </Step>

  <Step title="Enter Kevin Smith's code">
    Select Rave in the Redwoods, then enter: **right, left, left, down, down, right**. Kevin Smith's icon appears: you play as him when the game starts.

    <Screenshot src={m + 'smith_code/kevin_smith_icon.webp'} alt="Kevin Smith's icon in the lobby" credit={by} source={src} />

    <Tips>
      <Tip type="mistake" author="mmmrkennedy" source={src}>
        If you open another menu (Barracks, loadout…) after the code, the icon disappears: enter the code again.
      </Tip>
    </Tips>
  </Step>
</Checklist>
