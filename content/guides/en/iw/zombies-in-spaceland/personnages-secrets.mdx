Two secret characters can be played in Zombies in Spaceland with a code entered in the pre-game lobby, using the arrows on the D-pad or the keyboard.

<Tips>
  <Tip type="mistake" author="mmmrkennedy" source={src}>
    If you open another menu (Barracks, loadout…) after entering the code, the icon disappears: you have to enter the code again.
  </Tip>
</Tips>

## David Hasselhoff

<Checklist>
  <Step title="Finish the main Easter Egg once">
    Once is enough, in any game.
  </Step>

  <Step title="Enter David Hasselhoff's code">
    Select Zombies in Spaceland, then enter: **left, right, left, up, down**. David Hasselhoff's icon appears: you play as him when the game starts.

    <Screenshot src={m + 'hasselhoff_code/hasselhoff_icon.webp'} alt="David Hasselhoff's icon in the lobby" credit={by} source={src} />
  </Step>
</Checklist>

## Willard Wyler

<Checklist>
  <Step title="Unlock Director's Cut and beat Mephistopheles">
    Willard Wyler can only be played with **Director's Cut turned on**, and only after beating **Mephistopheles** on The Beast from Beyond. See [Unlock and use Director's Cut](../../the-beast-from-beyond/director-s-cut/) and [Final fight against Mephistopheles](../../the-beast-from-beyond/mephistopheles/).
  </Step>

  <Step title="Enter Willard Wyler's code">
    Select Zombies in Spaceland, then enter: **left, left, down, up, up, right**. Willard Wyler's icon appears: you play as him when the game starts.

    <Screenshot src={m + 'wyler_code/wyler_icon.webp'} alt="Willard Wyler's icon in the lobby" credit={by} source={src} />
  </Step>
</Checklist>

The main Easter Egg's ending cutscene only plays when you are Willard Wyler.
