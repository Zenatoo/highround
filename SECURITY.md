# Security Policy

**EN** · [FR](#français)

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

- Use GitHub's private reporting: **Security** tab → **Report a vulnerability**
- Or contact Zenato privately on Discord: `.zenato`

You will get an answer within 7 days. Once fixed, you will be credited in the release notes if you wish.

## Supported versions

Only the latest version of the website and the latest Windows `.exe` release receive security fixes.

## Downloading the Windows app

Only download the `.exe` from the official [Releases page](https://github.com/Zenatoo/highround/releases). Each release lists the file's SHA-256 checksum so you can verify it.

## Français

### Signaler une faille

**N'ouvre pas d'issue publique pour un problème de sécurité.**

- Utilise le signalement privé de GitHub : onglet **Security** → **Report a vulnerability**
- Ou contacte Zenato en privé sur Discord : `.zenato`

Tu auras une réponse sous 7 jours. Une fois corrigé, tu seras crédité dans les notes de version si tu le souhaites.

### Télécharger l'appli Windows

Télécharge le `.exe` uniquement depuis la [page Releases officielle](https://github.com/Zenatoo/highround/releases). Chaque version indique l'empreinte SHA-256 du fichier pour que tu puisses le vérifier.
